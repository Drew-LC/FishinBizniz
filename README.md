A quick local asymmetric multiplayer game, "Fishing Bizniz", where a Fisher and a Hunter compete or collaborate to get the most amount of fish possible for a higher score.

Created by Nuuluz (https://github.com/Junior627), Siso D. (https://github.com/siisodaa), and Drew-LC for a project for a university game course using Godot 4.4. All artwork was drawn by Nuuluz. Siso and Drew-LC programmed the game. Drew-LC designed the majority of the game.

I used royalty-free music from Purple Planet and sound effects from Freesound. Generative AI was not used in the creation of this game.

We permit the viewing and usage of any of this game's code for any reason. We permit the viewing and limited usage of this game's art, but we do not permit falsely claiming the art as your own or using it to train generative AI models.
